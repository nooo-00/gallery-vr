# gallery-vr

Mobile-first first-person walkthrough prototype for the EAST×EAST exhibition space.

- 163 cm body height reference
- approx. 153 cm eye height
- touch joystick + drag-to-look
- A/B/C wall presets
- metric position, grid, minimap

The geometry is a measurement-based approximation from the supplied floor plan and reference photos, not a survey-grade CAD model.
